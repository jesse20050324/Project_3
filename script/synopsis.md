# 剧本梗概层 · 块卡

> 层级：outline.md（宏观）→ 本文件（块卡/梗概）→ ch*.yaml（轮次定稿）。
> 每块一张卡。卡的边界就是创作边界：聚焦某块内部之前，先保证这张卡的入场/出口成立。
> 块不必等于幕：按「可独立聚焦的创作单元」划分——量大的幕拆块（幕8拆为8A/8B/8C），量小的合并（幕6+7并作一块）。
> 协作规则：设计迭代只发生在块卡和聊天里；outline.md 只收**已敲定**内容，一块敲定后才同步更新，不要每次小改都动它。
> 卡片字段：入场（需要什么旗标/关系值状态）、梗概（双线+玩家做什么）、载体、出口（收束成几个出口、立什么旗标）、现状。

## 幕5 熟悉期（展开版 · 设计稿待确认）

- 入场：至少一边问。**三个入场变体**：双问 / 男生问 / 女生问，只影响开场和温度，快速汇合进主线。
- 载体：转述复盘为主；本块还要**养成「找AI参谋/代笔」的习惯**——前期用甜的方式建立这个惯例，幕8.2 的实时求助通道才显得顺理成章。
- 出口：在一起=true，进块6+7；关系值累计（机制延后，不在此设计）。
- 本块任务：矛盾①③埋糖 + 双版本信息差主场 + AI军师惯例铺垫。

### 5.1 线上日常（块内最大篇幅）

- 5.1.1 开场变体轮次组（按幕4旗标三选一，很快汇合）：
  - 双问：表妹（=她同桌）被两边都要了联系方式，夹在中间哭笑不得；两人各自跟AI吐槽"我怎么开口"。
  - 男生问：他拿着微信半天不敢发第一句，跟AI商量；她侧只轻描淡写一句"我同桌把他微信推我了"。
  - 女生问：他没敢要，结果收到她好友申请，受宠若惊；她侧是她主动让同桌推的。
- 5.1.2 日常糖点轮次组（多拍，每拍=矛盾的一次糖化显形）：
  - 他秒回+「在干嘛」轰炸，她慢回短回 → 他读作「她好忙好独立」，她读作「他好在乎」。
  - 她聊事业规划（加班/攒钱/往上走），他听得觉得她发光；他「没啥打算，走一步看一步」被她读作「稳，不焦虑」。
  - 聊到她家里/前男友她就打岔 → 他读作「不想聊就不聊，体贴」；他从不聊家人只说「没啥事」→ 她读作「家庭简单省心」。
  - 吃什么去哪他都说「行、挺好的、听你的」→ 她读作「稳重随和」。
- 出口：线上热度到位，男生起念约见面。

### 5.2 第一次见面

- 5.2.1 约局：他鼓起勇气约（AI帮他参谋第一句邀约——AI军师惯例首次甜味使用）；她答应爽快，但当天临时改期一次（工作事由）。他侧小失落「她是不是不想去」跟AI吐槽；她侧真实原因=临时加班，玩家可见她其实期待。
- 5.2.2 见面当天：吃饭+散步。他的「随便」首次当面显形——去哪吃「都行」，点什么「你选吧」，她全程主导；她中途回了几次工作消息，他干坐着陪。
- 出口：见面平和收场，双方各怀小账。

### 5.3 事后双线复盘（信息差主场）

- 他版：今天挺好的，就是她老看手机，不过她忙嘛；我说了个笑话她居然笑了。
- 她版：他全程没意见，有点闷但也省心；我岔开前男友话题他没追问，挺体贴。
- 玩家对照真相：她那笑不是冲他的笑话；他没追问不是体贴，是没接住话头。两份版本并排，替对方找理由=糖。
- 出口：关系升温，有人要推进。

### 5.4 确定关系提案

- 谁开口：男生表白（焦虑型主导追求）；入场变体只影响他的忐忑程度和她的回应温度，不改走向。
- 5.4.1 表白排练：他跟AI排练措辞、选时机（实时求助的第二次甜味使用，进一步固化惯例）。
- 5.4.2 她侧纠结：她跟AI半露内心——「我有点慌，我怕太深入，但我确实挺喜欢跟他待着」（回避型内心第一次给玩家看）。
- 出口：她答应，在一起=true。

- 现状：展开版设计稿，待确认后进入轮次层（ch5.yaml）。

## 块8C 至暗与认识时刻（幕8后段 · 8.4~8.5）

- 入场：块8B完成。
- 梗概：8.4 朋友局晾一晚+散场爆发，双线暴怒复盘，潜台词喊出来（over闸门：双绝情当场散场）；8.5 认识时刻：AI对话本身即裁决现场，玩家回复措辞决定两侧各走认识到/外归因。

## 幕9 抉择与结局

- 入场：按幕8出口旗标分流。
- 梗概：A线=矛盾①停在表层没完没了地吵到散场；B线=认识方看见真相仍想留下、外归因方已走远；C线=双方说出各自那句认识（她就是这样的人，我为什么要求她必须敞开心扉 / 不是不喜欢你这个人，只是我不熟悉这样不知道怎么回应），冲突=关系的财富；D线=都看清楚了但攒的甜不够，祝福对方放手。
- 出口：全剧终（四线各自收尾）。
- 现状：梗概层。细化时四条结局线各拆一张卡。
