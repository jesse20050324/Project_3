# 终端音效

- AI 发送逐字回复时，根据现有打字间隔和文字长度估计输出时长。声音独立排程。跳过、播完、离开对话时清理剩余响点。
- 声音基础间隔 75–90 ms，带 ±6 ms 浮动与按时长分配的额外停顿。响点使用同一音量曲线：前 1 秒原音量，接下来 1.5 秒降至 40%。
- 玩家成功新增或替换记忆后播放合成两级确认音。
- 字符滴取自 cabled_mess 的 [Blip_C_08](https://freesound.org/people/cabled_mess/sounds/350861/)，CC0 1.0。游戏使用裁短、归一化及淡出的版本。
- 开机日志每行用轻量字符滴，减少动态效果跳过动画时也跳过日志音。新来信显示时播放已选的短双音。

## 默认混音

按 ITU-R BS.1770 与 EBU R 128 的方法区分响度和峰值。广播与流媒体的整段响度目标不适用于稀疏的互动提示音。本项目用 192 kHz 离线渲染测量数字采样峰值，并用 400 ms 窗口的 RMS 作为同场景比较；这两项不是认证真峰值或 LUFS 测量。

v0.7.16 测得开机、回复、来信、记忆确认峰值分别为 -27.8、-24.8、-22.1、-22.5 dBFS。将两路回复、两次来信和一次记忆确认在同一起点叠加，峰值从 -4.8 降到 -11.6 dBFS，最高 400 ms RMS 从 -23.5 降到 -30.6 dBFS。设备播放声压仍取决于用户设备及系统音量。
